# 🌙🔮✨ MystBrowser ✨🔮🌙
 > MystBrowser คือแอปเบราว์เซอร์ที่ออกแบบมาเพื่อการสร้างและใช้งานวิดเจ็ตด้วย HTML อย่างยืดหยุ่น เหมาะสำหรับนักพัฒนาและผู้ใช้ที่ต้องการปรับแต่งหน้าจอหรือเครื่องมือของตัวเองแบบไร้ขีดจำกัด

## ✨ Features
* สร้างวิดเจ็ตได้ง่ายด้วยไฟล์ .html
* ใช้เว็บไซต์เป็นวิดเจ็ตด้วยไฟล์ .url
* จัดการวิดเจ็ตหลายตัวในหน้าเดียว
* ควบคุมหน้าต่างได้อย่างอิสระ

## 🧷 Window Attachment Modes
* 🖼️ attachAsWallpaper
    * ฝังวิดเจ็ตเป็น Wallpaper
    * แสดงอยู่ “หลัง” Desktop icons
    * เหมาะสำหรับ background แบบ dynamic
* 🖥️ attachAsDesktop
    * ผูกวิดเจ็ตเข้ากับ Desktop layer
    * แสดงร่วมกับ icon / file บนหน้าจอ
    * เหมาะสำหรับ dashboard หรือ widget หลัก
* 📌 attachToTop
    * ปักวิดเจ็ตไว้บนสุดของทุกหน้าต่าง
    * ใช้เป็น overlay เช่น:
        * FPS monitor
        * Music control
        * Stream tools

   1. อัปเดตและการเปลี่ยนแปลง - MystBrowser อาจมีการอัปเดตหรือเปลี่ยนแปลงคุณสมบัติต่างๆ โดยไม่จำเป็นต้องแจ้งให้ผู้ใช้ทราบล่วงหน้า

9. การเปลี่ยนแปลงข้อตกลง
